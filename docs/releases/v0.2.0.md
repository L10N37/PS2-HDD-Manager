# PS2 HDD Manager v0.2.0

## 4 TB / Extended APA hardware-validated release

v0.2.0 is the first release promoted out of alpha after extensive real-hardware validation.

The release candidate was tested on a **Toshiba X300 4 TB HDD** (3.64 TiB host-visible) populated
with **1,274 PS2 games**.

## Hardware-validated highlights

- FHDB boots from Bank 0.
- Bank 0 and Bank 1 games install and launch on real PS2 hardware.
- AUTO placement correctly rolls from Bank 0 into Bank 1 when Bank 0 is full.
- Requeuing a large source set rapidly detects/skips already-installed exact games.
- Extended APA-aware OPL sees the multi-bank game set.
- Installed-title fixes invalidate stale OPL `games.bin` data so OPL rebuilds from real HDL headers.
- Direct HDD IGR return works through:
  `hdd0:PP.FHDB.APPS:pfs:/OPL/IGR.ELF`
- Fresh HDD setup now installs HDD IGR return by default when OPL provisioning is selected.
- Bank-0 artwork is available across the multi-bank library.

## Large-library / transfer improvements

The queue now keeps an in-memory installed-game identity cache and uses targeted verification rather
than repeatedly walking every bank around every install.

AUTO space accounting remains fast for the bulk of a bank, then switches to authoritative live APA
checks near capacity. This fixes the accumulated allocation-estimate drift exposed by the long 4 TB
stress run.

If the selected source set cannot fit on the target HDD, a preflight capacity warning is shown before
the long transfer starts.

## HDD IGR return

The normal UI now exposes:

- **Install HDD IGR Return**
- **Disable HDD IGR Return**

Fresh formatting/provisioning includes:

```text
[x] Install HDD IGR Return (recommended)
```

The matching OPL ELF is installed both as `OPNPS2LD.ELF` and `IGR.ELF`; multi-bank disks use the
matching Extended APA-aware OPL build for both copies.

## PC pane / Game ID improvements

- Optional **Scan Game IDs** checkbox.
- Scanning defaults to off and is remembered.
- Asynchronous Game-ID results.
- Non-recursive folder probing.
- Stale in-flight results discarded after disabling.
- Corrected metadata-column spacing.
- Zero-padded `MM/dd/yy` Date Modified display.

## Final release-candidate fixes

- **Scan Game IDs is isolated to the PC pane.** Toggling it no longer emits a broad model-layout reset or causes the populated PS2 HDD pane to rescan/reload.
- Added the new PS2-themed application icon for the Qt runtime, Fedora/KDE desktop integration and Windows executable resources.
- Added KDE/Wayland desktop-file identity and hicolor icon installation so the running application resolves to the correct taskbar icon.

## Platform status

**Fedora/Linux:** real-hardware validated.

**Windows:** builds exist, but physical-HDD formatting/install workflows have not received the same
hardware validation and should still be treated as experimental.

## Safety

PS2 HDD Manager performs raw physical-disk writes. Always verify the selected target before destructive
operations and keep backups of important data.
